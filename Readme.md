# 🎬 Film Recommendation Web Application

## 📝 Overview
This project is a simple yet effective **web application** that provides **film recommendations** using **content-based filtering**.  
It helps users discover new movies by suggesting films similar to the ones they already like.

---

## 🚀 Key Features

### 🎯 Content-Based Filtering
- Analyzes the films that users have liked.  
- Provides **10 personalized movie recommendations** based on similarity.

### 💻 User-Friendly Interface
- Built using **Python**, **Flask**, and **Scikit-learn**.  
- Offers a clean, intuitive, and responsive interface for an enjoyable user experience.

---

## 🎯 Objective
The goal of this application is to provide users with an effortless way to discover new movies that match their tastes and preferences — enhancing their overall film-watching experience.
